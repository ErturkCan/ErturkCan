# Profile design

Olive accent and transparent “Can Ertürk” wordmark, shared with the personal design language. The body uses native GitHub Markdown in one column: short work-led paragraphs, small headings, a compact linked code list and selected results in bold.

Avoid panels, coloured title bands, repeated technology tags and a separate box for every fact. Keep project descriptions concise without removing qualifications or meaningful outcomes; implementation details belong in each repository. The green-dot wordmark renders at 280px. Retain a short personal line and put contact links at the end. GitHub controls the text font and theme; light/dark wordmark variants are local SVG files.

`design/tokens.json` records the palette. Existing artwork sources remain versioned; the current README uses only the wordmark. The 30+ FPS result and 50,000+ mask holders produced and sold are based on Can's account. Do not invent model accuracy or new performance figures.
